Trabajo Práctico N° 1: Etiquetas HTML

Desarrollo Web

1. Encabezados y Textos

<h1> a <h6>

Forma:

<h1>Título principal</h1>
<h2>Subtítulo</h2>

Definición: Define los títulos y jerarquía del texto en la página. El <h1> es el más importante y se recomienda usarlo una sola vez por documento.

<p>

Forma:

<p>Este es un párrafo de texto general.</p>

Definición: Agrupa un bloque de texto común, añadiendo automáticamente separación superior e inferior.

2. Contenedores y Estructura

<div>

Forma:

<div>Contenido agrupado para estilos</div>

Definición: Contenedor genérico en bloque sin significado semántico específico, utilizado para estructurar y aplicar estilos.

<section>

Forma:

<section>
    <h2>Sección temática</h2>
</section>

Definición: Agrupa contenido relacionado temáticamente que comparte un mismo contexto dentro del documento.

<article>

Forma:

<article>
    <h2>Noticia o Post</h2>
    <p>...</p>
</article>

Definición: Representa una pieza de contenido autónoma e independiente, como una entrada de blog, artículo o tarjeta de producto.

<nav>

Forma:

<nav>
    <a href="#">Inicio</a>
    <a href="#">Contacto</a>
</nav>

Definición: Contenedor destinado a las secciones de enlaces de navegación principales del sitio web.

<footer>

Forma:

<footer>
    <p>© 2026 Mi Sitio Web</p>
</footer>

Definición: Define el pie de página de una sección o de todo el documento, conteniendo datos de contacto, autoría o derechos.

3. Formularios e Interfaz

<form>

Forma:

<form action="enviar.php" method="POST">
    <!-- Campos del formulario -->
</form>

Definición: Contenedor interactivo para recopilar datos ingresados por el usuario y enviarlos a un servidor web.

<select>

Forma:

<select>
    <option>Opción 1</option>
    <option>Opción 2</option>
</select>

Definición: Crea un menú desplegable interactivo que permite al usuario seleccionar una o varias opciones de una lista.

4. Multimedia

<img>

Forma:

<img src="imagen.jpg" alt="Descripción de la imagen">

Definición: Inserta una imagen en la página web utilizando la ruta del archivo (src) y un texto alternativo descriptivo (alt).
